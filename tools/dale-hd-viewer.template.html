What this is

Dale rebuilt as one detailed character under 18,000 triangles: sculpted as distance fields in code, meshed at 1–3.5 mm, decimated to budget, skinned to his existing game rig, so every clip here is a real game clip.

Textures

A 2048² colour map painted per texel (skin, iris, camel check, silk tie), a normal map baked from the dense sculpt plus painted micro-detail (pores, weave, combed hair), and a roughness map.

Not yet

No face shape keys (hurt, KO, win) and no umbrella prop yet. The fingers have three joints each (bones added to the game rig, curls rewritten from its clips). The game draws fighters with a simpler lit material, so normal maps would need a material change there.
